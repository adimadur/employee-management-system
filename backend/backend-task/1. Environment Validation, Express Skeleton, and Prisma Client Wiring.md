# 1. Environment Validation, Express Skeleton, and Prisma Client Wiring

Status: Not Started  
Mandatory: Yes  
Depends On: Task 0

## Goal

Add the executable app skeleton so the backend can boot consistently with validated environment variables and a shared Prisma client.

## Confirmed Current Behavior

- No `src/app.ts`, `src/server.ts`, or environment loader exists.
- No Prisma client singleton exists.
- No backend `.env.example` exists yet.

## Implementation Scope

- Add environment parsing and validation for all required backend variables.
- Create `src/app.ts` and `src/server.ts` with a clean Express bootstrap.
- Wire a shared Prisma client singleton in `src/lib/prisma.ts`.
- Add base route mounting under `/api`.
- Keep the app runnable even before all business routes exist.

## Files Expected To Change

- `backend/.env.example`
- `backend/src/app.ts`
- `backend/src/server.ts`
- `backend/src/config/env.ts`
- `backend/src/lib/prisma.ts`
- `backend/src/routes/`

## Acceptance Criteria

- Startup fails fast on missing or invalid required environment variables.
- The server reads `process.env.PORT` and can boot with a minimal `/api` route structure.
- Prisma client creation is centralized and reusable across services.
- The backend has a reviewer-friendly `.env.example` contract.

## Verification

- `npm run typecheck`
- `npm run build`
- `node dist/server.js`
