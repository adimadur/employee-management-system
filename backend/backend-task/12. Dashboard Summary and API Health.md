# 12. Dashboard Summary and API Health

Status: Not Started  
Mandatory: Yes  
Depends On: Tasks 6, 8, 10, 11

## Goal

Implement the dashboard metrics endpoint and a lightweight health route once the core employee data flows exist.

## Confirmed Current Behavior

- No `GET /api/dashboard/summary` endpoint exists.
- No backend health endpoint exists.
- Dashboard metrics cannot be computed yet because the employee flows are not implemented.

## Implementation Scope

- Add `GET /api/dashboard/summary` for Super Admin and HR Manager.
- Compute total employees, active employees, inactive employees, and distinct department count.
- Ensure all counts exclude soft-deleted employees.
- Add `GET /api/health` as a minimal reviewer-friendly health check.
- Keep the health response generic and free of secrets or deployment details.

## Files Expected To Change

- `backend/src/routes/dashboard.routes.ts`
- `backend/src/controllers/dashboard.controller.ts`
- `backend/src/services/dashboard.service.ts`
- `backend/src/app.ts`

## Acceptance Criteria

- Dashboard summary response matches the documented shape.
- Employee role is forbidden from accessing dashboard metrics.
- Department count uses distinct non-deleted department values.
- Health endpoint responds successfully without leaking environment information.

- `npm run typecheck`
- `npm run build`
- `npm run test`
