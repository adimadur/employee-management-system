# 3. Seed Data and Reviewer Accounts

Status: Not Started  
Mandatory: Yes  
Depends On: Task 2

## Goal

Create idempotent seed data so the backend starts with reviewer-ready accounts, departments, statuses, and a small hierarchy.

## Confirmed Current Behavior

- No Prisma seed script exists.
- No seeded Super Admin, HR Manager, or employee records exist.
- No sample hierarchy or inactive records exist for dashboard and organization features.

## Implementation Scope

- Add a Prisma seed script wired into package scripts.
- Seed one Super Admin account from environment variables.
- Seed at least one HR Manager and several employees across multiple departments.
- Include both active and inactive users.
- Include a small reporting hierarchy that later tasks can use for organization reads.
- Hash passwords with bcrypt before storage.

## Files Expected To Change

- `backend/prisma/seed.ts`
- `backend/package.json`
- `backend/.env.example`
- `backend/README.md`

## Acceptance Criteria

- Seed is idempotent or safely repeatable.
- Seeded credentials are reviewable through env configuration rather than hardcoded secrets.
- Passwords are stored as bcrypt hashes, not plain text.
- Seeded data is sufficient to exercise RBAC, dashboard counts, and hierarchy features.

## Verification

- `npm run prisma:seed`
- `npx prisma studio`
